02 / MAKE IT TANGIBLE

Small tokens.
Real trade-offs.

Turn a model price into a product decision. Change the workload and see how quickly it adds up.

What does this estimate include?

Text input and output across all calls. Set calls per task to include retries or agent loops. Output should include billed reasoning tokens. Excludes cache fees and discounts, tools, grounding, storage, taxes, and infrastructure. No API calls are made.

Example: 2,000 in + 500 out at $2 / $10 per million = $0.009 per call.
