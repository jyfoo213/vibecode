THE AI PM FIELD GUIDE

WORDS YOU NOW OWN

For work
you already do.

Catch yourself doing one, say the word once.

Context engineering

Everything the model sees, not just the prompt.

Context window

Working memory for one session. Finite.

Retrieval (RAG)

Fetch documents when needed, not all at once.

Grounding

Answer from the source, not from memory.

Harness

Everything that isn't the model.

Agent loop

Plan → act → look → decide.

MCP

The standard plug for tools and data.

Guardrails

What behaviour is disallowed, and what happens then.

Human-in-the-loop

A person checks before the agent proceeds.

Eval

Measurement against a standard. It changes nothing.

Golden dataset

Fixed test cases, known-good answers.

Gold labels

Human-verified correct answers. Shopee, at scale.

Failure mode / taxonomy

Name how it breaks, then group the names.

LLM-as-judge

A model scoring a model. The PRD agent is one.

Rubric

Criteria, scale, what good looks like.

Human–model agreement

How often the judge matches humans. The trust check.

Regression

The new prompt broke the thing that worked.

Traces

Step-by-step record of one run.

Drift

Good scores, quietly going stale.

Hallucination

Fluent, wrong, invented. Turn it into an eval case.

SFT / RLHF

Learn from demonstrations; learn from preferences.

Inference

The model running. Cost and speed are PM concerns.

Capability vs reliability

Products fail on the second, not the first.

Applied vs model PM

Build on models, or build the model. You target the first.
