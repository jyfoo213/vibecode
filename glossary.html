WORDS YOU NOW OWN

The vocabulary for
work you already do.

Don't memorise. When you catch yourself doing one of these, say the word once — recognition in context is what makes it stick.

Context engineering

Deciding everything the model sees for the next step — instructions, documents, history, user data — not just the prompt.

Context window

The model's working memory for one session. Finite, which is why selection matters.

Retrieval (RAG)

Fetching relevant documents into the window at the moment they're needed, instead of pasting everything.

Grounding

Anchoring output in real source material so the model doesn't improvise. "Answer from the repo, not from memory."

Harness

Everything that isn't the model: instructions, context, skills, memory, permissions, tools, checks, and the loop.

Agent loop

Plan → act → look at the result → decide what's next. The same loop, at org scale, is the "companies as loops" idea.

MCP

Model Context Protocol: the standard plug connecting tools and data sources to a model.

Guardrails

The safety and policy limits wrapped around behaviour — what outputs or actions are disallowed, and what happens when the model tries.

Human-in-the-loop (HITL)

A designed checkpoint where a person reviews, approves, or corrects before the agent proceeds.

Eval

A structured measurement of behaviour against a standard. Measurement only — it doesn't change the model.

Golden dataset

A fixed set of test cases with known-good answers, run repeatedly so results are comparable.

Gold labels

The human-verified correct answers inside an eval set. The Shopee labelling operation produced these at scale.

Failure mode / taxonomy

A recurring, nameable way the system gets it wrong — and the organised list of them, so fixes target categories, not anecdotes.

LLM-as-judge / autorater

Using a model to score another model's outputs against a rubric, at a scale humans can't. The PRD-scoring agent is one.

Rubric

The scoring guide the judge applies: criteria, scale, what good looks like.

Human–model agreement

How often the model's scores match human scores on the same outputs. The trust check on any judge.

Regression

A previously-passing case that starts failing after a change. "The new prompt broke the thing that worked."

Traces

The step-by-step record of one agent run: each tool call, decision, and output, in order.

Drift

Behaviour quietly changing over time, so yesterday's good scores no longer hold.

Hallucination

Fluent output that is factually wrong or invented — a failure mode you detect via traces, then convert into eval cases.

SFT / RLHF

Post-training shaping: learning from demonstrations (SFT), and learning from ranked human preferences (RLHF).

Inference

The model actually running and producing answers, as opposed to training. Its cost and speed are PM concerns.

Capability vs reliability

What a model can do at all, vs whether it does it consistently. Products fail on reliability more than capability.

Applied AI PM vs model PM

Model PMs build the model with researchers; applied AI PMs build products on top of models. Your target roles are the second, with fluency in the first's vocabulary.
