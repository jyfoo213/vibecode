When you want to check an answer.

A verdict checks one answer against a stated question and rubric. A self-written answer can still be wrong; inspect the primary evidence and record uncertainty. Your notes should explain the gap so a future agent can improve the answer.

How does the bank evolve?

Agents add requested questions to the versioned question dataset. Stable IDs preserve review history. If a case changes substantively, its revision increases and your old verdict is shown as stale until you review again. This page does not edit the repository.

What is included in an export?

Case IDs, revisions, questions, current verdicts and your notes. Treat an export as a dated review artifact. It contains what you wrote, so check it before sharing. An agent can use it as feedback; it does not automatically update the repository.
